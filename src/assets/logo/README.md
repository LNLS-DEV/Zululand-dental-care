# Logo assets

Real logo, supplied by the client — no longer a placeholder.

- `zululand-logo-full.png` — full lockup (icon + "ZULULAND / DENTAL CARE"
  text), background made transparent. Used in the **Footer**, where there's
  enough vertical room to keep the text legible.
- `zululand-logo-icon.png` — the circular tooth mark only, cropped from the
  same supplied file, background made transparent. Used in the **Navbar**
  (paired with a text label, since the full square lockup doesn't read well
  at sticky-nav height) and to generate the favicon/apple-touch-icon in
  `public/`.

Both were produced by removing the flat white background from the original
supplied PNG (border-connected flood fill, so the white *inside* the artwork —
the tooth silhouette, letter counters — was left untouched), then resized and
compressed for web use. No artwork was redrawn or altered.

## Naming discrepancy worth checking

The supplied logo reads **"Zululand Dental Care."** Every other piece of
content on this site (page copy, meta tags, the original written brief) uses
**"Zululand Dental Care."** I kept the site text as "Practice" since
that's what was explicitly specified to keep exactly — but the logo now
visually says "Care" right next to it in the nav and footer. Worth deciding
which is the real, current business name and telling me — a one-line fix
either way (either update the site text, or point me to an updated logo).
